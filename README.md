# Apurva Portfolio

Modern React + Vite personal portfolio.

## Run

```bash
npm install
npm run dev
```

Then open the URL shown by Vite, normally http://localhost:5173.

## Production build

```bash
npm run build
npm run preview
```

## Personalize

- Replace the email address in `src/App.jsx`.
- Replace GitHub and LinkedIn URLs in `src/App.jsx`.
- Put your real resume at `public/resume.pdf`.
- Update education details, achievements and experience with verified information.
